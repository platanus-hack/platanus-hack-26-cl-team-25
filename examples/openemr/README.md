# OpenEMR 8.2.0 + Inmune

Onboarding of the unmodified OpenEMR v8_2_0 (commit 6125a2fd8089) to Inmune's generic runtime, the same flow
as the Tienda. Full guide (Spanish): [docs/openemr.md](../../docs/openemr.md).

    python examples/openemr/fetch.py                  # clone + verify the tag, add the onboarding, tag openemr-t0
    bin/immune up --project examples/openemr/app      # gateway 127.0.0.1:8280, dashboard 127.0.0.1:8290
    python examples/openemr/legit.py                  # Clínica Delta staff (legitimate traffic)
    python examples/openemr/attacks.py                # attacks on real OpenEMR surfaces

| Path | What |
|---|---|
| `fetch.py` | pinned clone, version check, onboarding overlay, `openemr-t0` |
| `overlay/Dockerfile.immune` | the pinned official image + read-only/non-root runtime |
| `overlay/immune-runtime/` | Apache config, PHP ini, `sqlconf.php` from env, start, seed (installer + Clínica Delta), `whoami.php`, `tests.sh` |
| `overlay/.immune/config.yaml` | the project config (`runtime: generic`, `database.kind: mysql`, tracer, introspect auth) |
| `overlay/.immune/openapi.yaml` | generated by `gen_openapi.py` from the tag (REST/FHIR spec + every UI script) |
| `overlay/.immune/shadow/columns.yaml` | generated by `gen_columns.py` from the installed schema (283 tables) |
| `overlay/.immune/openemr_identity.py` | shadow identity profile (users, login, CSRF) |
| `legit.py`, `attacks.py` | demo traffic |

No OpenEMR file is planted with a vulnerability. See REVIEW_NOTES.md.
